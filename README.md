# AQA Training

**Путь от Manual QA к Automation QA**

Практический проект для последовательного изучения JavaScript, TypeScript и инструментов автоматизации тестирования.

Цель проекта - освоить необходимую техническую базу, научиться самостоятельно разбираться в AQA-проектах, писать и поддерживать автотесты, находить и исправлять ошибки.

## Практика

Обучение строится на практических задачах, приближённых к реальной работе QA-инженера.

В процессе обучения предстоит:

- Писать JavaScript-код для решения тестовых задач
- Работать с тестовыми данными и проверками
- Создавать функции и вспомогательные инструменты
- Писать UI- и API-автотесты
- Использовать Page Object Model
- Разбираться в структуре существующих AQA-проектов
- Отлаживать тесты и анализировать причины падений

## Принципы обучения

1. Последовательное изучение тем без пропуска фундаментальных знаний
2. Теория с практическими примерами
3. Практические задания после каждой темы
4. Разбор решений и исправление ошибок
5. Контрольные вопросы для закрепления материала
6. Постепенный переход от простых задач к реальным AQA-сценариям
