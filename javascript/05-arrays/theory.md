# 05. Массивы в JavaScript

## 1. Что такое массив

**Массив (`Array`)** — структура данных, которая позволяет хранить несколько значений в одной переменной.

Вместо отдельных переменных:

```js
const test1 = "Authorization";
const test2 = "Registration";
const test3 = "Payment";
```

Можно использовать один массив:

```js
const tests = ["Authorization", "Registration", "Payment"];
```

Массив может содержать значения разных типов:

```js
const testData = ["Login test", 200, true, null];
```

Однако на практике часто используют массивы для хранения однотипных данных.

## 2. Создание массива

Основной способ создания массива — квадратные скобки:

```js
const statuses = [200, 201, 400, 404, 500];
```

Можно создать пустой массив:

```js
const failedTests = [];
```

Также существует конструктор `Array`:

```js
const tests = new Array("Login", "Logout");
```

В обычном JavaScript-коде чаще используют квадратные скобки `[]`.

## 3. Индексы массива

У каждого элемента массива есть индекс — его порядковый номер.

**Индексация массива начинается с нуля.**

```js
const statuses = [200, 201, 404, 500];

console.log(statuses[0]); // 200
console.log(statuses[1]); // 201
console.log(statuses[3]); // 500
```

Если обратиться к несуществующему индексу, JavaScript вернёт `undefined`:

```js
console.log(statuses[10]); // undefined
```

Это не вызывает ошибку само по себе.

## 4. Свойство length

Свойство `length` возвращает количество элементов массива:

```js
const statuses = [200, 201, 404, 500];

console.log(statuses.length); // 4
```

`length` часто используется для получения последнего элемента массива:

```js
const lastStatus = statuses[statuses.length - 1];

console.log(lastStatus); // 500
```

Почему используется `- 1`?

Потому что `length` возвращает количество элементов, а индексация начинается с нуля.

Например, если в массиве четыре элемента, их индексы — `0`, `1`, `2` и `3`.

## 5. Изменение элементов массива

Массив, объявленный через `const`, можно изменять.

`const` запрещает переназначение переменной, но не изменение содержимого массива.

```js
const statuses = [200, 201, 404];

statuses[2] = 500;

console.log(statuses); // [200, 201, 500]
```

Однако переназначить сам массив нельзя:

```js
const statuses = [200, 201, 404];

statuses = [200, 500]; // TypeError
```

Изменение содержимого существующего массива называется **мутацией**.

## 6. Добавление и удаление элементов

У массивов есть четыре основных метода для добавления и удаления элементов.

### 6.1. push()

Метод `push()` добавляет элемент в конец массива.

```js
const tests = ["Login", "Logout"];

tests.push("Registration");

console.log(tests);
// ["Login", "Logout", "Registration"]
```

Метод изменяет исходный массив и возвращает его новую длину.

### 6.2. pop()

Метод `pop()` удаляет последний элемент массива.

```js
const tests = ["Login", "Logout"];

tests.pop();

console.log(tests);
// ["Login"]
```

Метод изменяет исходный массив и возвращает удалённый элемент.

### 6.3. unshift()

Метод `unshift()` добавляет элемент в начало массива.

```js
const tests = ["Login", "Logout"];

tests.unshift("Registration");

console.log(tests);
// ["Registration", "Login", "Logout"]
```

Метод изменяет исходный массив и возвращает его новую длину.

### 6.4. shift()

Метод `shift()` удаляет первый элемент массива.

```js
const tests = ["Login", "Logout"];

tests.shift();

console.log(tests);
// ["Logout"]
```

Метод изменяет исходный массив и возвращает удалённый элемент.

### 6.5. Сравнение методов

| Метод       | Действие                   | Что возвращает      |
| ----------- | -------------------------- | ------------------- |
| `push()`    | Добавляет элемент в конец  | Новую длину массива |
| `pop()`     | Удаляет последний элемент  | Удалённый элемент   |
| `unshift()` | Добавляет элемент в начало | Новую длину массива |
| `shift()`   | Удаляет первый элемент     | Удалённый элемент   |

**Важно:** все четыре метода изменяют исходный массив.

## 7. Поиск элементов в массиве

### 7.1. includes()

Метод `includes()` проверяет, содержится ли указанное значение в массиве.

Возвращает `true` или `false`.

```js
const statuses = [200, 201, 404, 500];

console.log(statuses.includes(200)); // true
console.log(statuses.includes(403)); // false
```

Применение в QA:

```js
const expectedStatuses = [200, 201];

const actualStatus = 200;

if (expectedStatuses.includes(actualStatus)) {
  console.log("Status is expected");
}
```

### 7.2. indexOf()

Метод `indexOf()` возвращает индекс первого найденного элемента.

Если элемент не найден, возвращает `-1`.

```js
const statuses = [200, 201, 404, 500];

console.log(statuses.indexOf(404)); // 2
console.log(statuses.indexOf(403)); // -1
```

**Важно:** `indexOf()` возвращает индекс, а не `true` или `false`.

## 8. Перебор массива

Перебор массива позволяет последовательно обработать каждый его элемент.

### 8.1. Цикл for

Для перебора массива можно использовать обычный цикл `for`:

```js
const results = ["PASSED", "FAILED", "PASSED"];

for (let i = 0; i < results.length; i++) {
  console.log(results[i]);
}
```

Результат:

```text
PASSED
FAILED
PASSED
```

Разберём части цикла:

- `let i = 0` — начинаем с первого индекса массива.
- `i < results.length` — выполняем цикл, пока индекс меньше длины массива.
- `i++` — увеличиваем индекс на единицу после каждой итерации.
- `results[i]` — получаем элемент массива по текущему индексу.

Если необходимо вывести привычную нумерацию элементов с единицы, можно использовать `i + 1`:

```js
for (let i = 0; i < results.length; i++) {
  console.log(`Test #${i + 1}: ${results[i]}`);
}
```

### 8.2. Цикл for...of

`for...of` — более компактный способ перебора значений массива.

```js
const results = ["PASSED", "FAILED", "PASSED"];

for (const result of results) {
  console.log(result);
}
```

Цикл последовательно получает значения массива. Для простого перебора не требуется вручную управлять индексом.

### 8.3. Сравнение for и for...of

| `for`                        | `for...of`                             |
| ---------------------------- | -------------------------------------- |
| Даёт доступ к индексу        | Перебирает значения                    |
| Позволяет управлять индексом | Не требует ручного управления индексом |
| Удобен, когда нужен индекс   | Удобен для простого перебора элементов |

Пример, когда нужен индекс:

```js
const tests = ["Login", "Payment", "Registration"];

for (let i = 0; i < tests.length; i++) {
  console.log(`Test ${i + 1}: ${tests[i]}`);
}
```

Пример, когда достаточно значения:

```js
for (const test of tests) {
  console.log(`Running test: ${test}`);
}
```

## 9. Типичные ошибки и важные нюансы

### 9.1. Путаница между длиной массива и последним индексом

```js
const tests = ["Login", "Payment", "Registration"];

console.log(tests.length); // 3
console.log(tests[2]); // "Registration"
```

Длина массива равна `3`, но индекс последнего элемента — `2`.

### 9.2. Неправильное обращение к последнему элементу

```js
const tests = ["Login", "Payment", "Registration"];

console.log(tests[tests.length]); // undefined
```

Для получения последнего элемента нужно использовать `tests.length - 1`.

### 9.3. Неправильное использование indexOf()

```js
const statuses = [200, 201, 404];

console.log(statuses.indexOf(403)); // -1
```

`-1` означает, что элемент не найден. Нельзя считать, что любое возвращённое число означает успешный поиск.

### 9.4. Автоматический подсчёт всех остальных значений как FAILED

```js
if (testResults[i] === "PASSED") {
  passedTests++;
} else {
  failedTests++;
}
```

Такой код считает любой результат, отличный от `"PASSED"`, проваленным.

Для учебного задания с двумя возможными значениями это допустимо. В реальных тестовых системах могут существовать и другие статусы, поэтому их следует учитывать отдельно.

| Перебрать значения         | `for (const item of items)`              |
