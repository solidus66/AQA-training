# 03. Циклы в JavaScript

## 1. Что такое циклы

Циклы позволяют многократно выполнять один и тот же блок кода, пока выполняется определённое условие.

В AQA циклы используются для:

- Перебора списка тест-кейсов
- Повторного выполнения теста
- Проверки нескольких элементов на странице
- Обработки массива API-ответов
- Подсчёта результатов тестирования

В JavaScript есть несколько видов циклов:

- `for`
- `while`
- `do...while`

Также существуют операторы управления циклами:

- `break`
- `continue`

## 2. Цикл `for`

Используется, когда заранее известно количество повторений или есть понятный счётчик.

Синтаксис:

```js
for (инициализация; условие; изменение) {
  // код, который будет выполняться
}
```

Пример:

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

Результат:

```text
1
2
3
4
5
```

Разберём конструкцию:

```js
for (let i = 1; i <= 5; i++)
```

В ней три части:

| Часть    | Назначение                                            |
| ------------- | --------------------------------------------------------------- |
| `let i = 1` | Инициализация счётчика                     |
| `i <= 5`    | Условие продолжения цикла                |
| `i++`       | Изменение счётчика после итерации |

### Как работает `for`

Последовательность выполнения:

1. Создаётся переменная `i` со значением `1`.
2. Проверяется условие `i <= 5`.
3. Если условие истинно, выполняется тело цикла.
4. Выполняется `i++`.
5. Снова проверяется условие.
6. Цикл продолжается, пока условие истинно.
7. Когда условие становится ложным, цикл завершается.

**Важно:** `i++` увеличивает значение переменной на единицу.

Это эквивалентно:

```js
i = i + 1;
```

Также можно использовать:

```js
i += 1;
```

### Пример с AQA

```js
for (let testNumber = 1; testNumber <= 3; testNumber++) {
  console.log(`Running test #${testNumber}`);
}
```

Результат:

```text
Running test #1
Running test #2
Running test #3
```

Каждая итерация цикла выполняет один и тот же код, но с новым значением `testNumber`.

## 3. Цикл `while`

Используется, когда количество повторений заранее неизвестно и цикл должен выполняться, пока условие истинно.

Синтаксис:

```js
while (условие) {
  // код, который будет выполняться
}
```

Пример:

```js
let attempt = 1;

while (attempt <= 5) {
  console.log(`Attempt ${attempt}`);
  attempt++;
}
```

Результат:

```text
Attempt 1
Attempt 2
Attempt 3
Attempt 4
Attempt 5
```

### Как работает `while`

1. Проверяется условие.
2. Если оно истинно, выполняется тело цикла.
3. После выполнения тела цикл возвращается к проверке условия.
4. Если условие ложно, цикл завершается.

**Главное отличие от `for`:** в `while` инициализация и изменение счётчика обычно находятся отдельно от заголовка цикла.

### Важный момент

Если забыть изменить переменную, участвующую в условии, цикл может никогда не завершиться.

Пример ошибки:

```js
let attempt = 1;

while (attempt <= 5) {
  console.log(attempt);
}
```

Здесь `attempt` всегда равен `1`.

Условие `attempt <= 5` постоянно истинно.

Получаем бесконечный цикл.

## 4. Цикл `do...while`

Отличается от `while` тем, что сначала выполняет тело цикла, а уже потом проверяет условие.

Синтаксис:

```js
do {
  // код, который будет выполнен
} while (условие);
```

Пример:

```js
let attempt = 1;

do {
  console.log(`Attempt ${attempt}`);
  attempt++;
} while (attempt <= 3);
```

Результат:

```text
Attempt 1
Attempt 2
Attempt 3
```

### Главное отличие `while` от `do...while`

`while` сначала проверяет условие, а потом выполняет код.

`do...while` сначала выполняет код, а потом проверяет условие.

Поэтому `do...while` гарантированно выполнит тело цикла хотя бы один раз.

Даже если условие изначально ложно:

```js
let attempt = 10;

do {
  console.log("Test execution");
} while (attempt < 5);
```

Результат:

```text
Test execution
```

Код выполнился один раз, несмотря на ложное условие.

## 5. Оператор `break`

`break` полностью прекращает выполнение цикла.

Пример:

```js
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }

  console.log(i);
}
```

Результат:

```text
1
2
3
4
```

Когда `i` становится равным `5`, выполняется `break`.

Цикл полностью завершается.

### Применение в AQA

Представим, что тест выполняется несколько раз, пока не получит успешный результат.

Если тест прошёл — дальнейшие попытки не нужны.

```js
let attempt = 1;

while (attempt <= 5) {
  console.log(`Attempt ${attempt}`);

  if (attempt === 3) {
    console.log("Test passed");
    break;
  }

  attempt++;
}
```

Результат:

```text
Attempt 1
Attempt 2
Attempt 3
Test passed
```

После `break` цикл больше не выполняется.

**Важный нюанс:** `break` завершает цикл немедленно. Код после него в текущей итерации не выполняется. Поэтому если увеличение счётчика расположено после `break`, оно не произойдёт.

## 6. Оператор `continue`

`continue` пропускает оставшуюся часть текущей итерации и переходит к следующей.

Пример:

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }

  console.log(i);
}
```

Результат:

```text
1
2
4
5
```

Когда `i` становится равным `3`, выполняется `continue`.

Оставшаяся часть текущей итерации пропускается.

Но сам цикл не прекращается.

### Разница между `break` и `continue`

| Оператор | Что делает                                  |
| ---------------- | ---------------------------------------------------- |
| `break`        | Полностью завершает цикл       |
| `continue`     | Пропускает текущую итерацию |

### Применение в AQA

Представим, что у нас есть список тестов, и один из них упал.

Мы хотим вывести результат каждого теста, но для упавшего использовать отдельную обработку.

```js
const totalTests = 5;
const failedTest = 3;

for (let i = 1; i <= totalTests; i++) {
  if (i === failedTest) {
    console.log(`Test #${i}: FAILED`);
    continue;
  }

  console.log(`Test #${i}: PASSED`);
}
```

Результат:

```text
Test #1: PASSED
Test #2: PASSED
Test #3: FAILED
Test #4: PASSED
Test #5: PASSED
```

**Важно:** `continue` не завершает цикл. Он пропускает только оставшуюся часть текущей итерации.

## 7. Бесконечные циклы

Бесконечный цикл — это цикл, условие завершения которого никогда не становится ложным либо выполнение не доходит до выхода из цикла.

Пример:

```js
while (true) {
  console.log("Running...");
}
```

Такой цикл будет выполняться бесконечно, пока процесс не будет остановлен извне.

Другой пример:

```js
for (let i = 1; i > 0; i++) {
  console.log(i);
}
```

Условие ``i > 0`` остаётся истинным даже после достижения значения ``2 ** 53`` (``9007199254740992``).

В JavaScript тип ``Number`` не может точно представлять все целые числа за пределами диапазона безопасных целых чисел (``Number.MAX_SAFE_INTEGER``).

При достижении значения ``9007199254740992`` прибавление ``1`` уже не изменяет ``i`` из-за ограниченной точности чисел.

В результате:

- ``i`` перестаёт увеличиваться.
- Условие ``i > 0`` остаётся истинным.
- Цикл продолжает выполняться бесконечно.

Это пример того, как потеря точности чисел может привести к бесконечному циклу.

## 8. Накопление значений в цикле

Цикл можно использовать не только для вывода значений, но и для накопления результата.

Например, если нужно посчитать суммарное время выполнения нескольких тестов, можно создать переменную-накопитель.

```js
const testCount = 5;
const executionTime = 3;
let totalExecutionTime = 0;

for (let test = 1; test <= testCount; test++) {
  totalExecutionTime += executionTime;
}

console.log(totalExecutionTime);
```

Результат:

```text
15
```

### Как это работает

1. `totalExecutionTime = 0` — начальное значение накопителя.
2. Цикл выполняется пять раз.
3. На каждой итерации к накопителю прибавляется `executionTime`.
4. После завершения цикла в накопителе находится общая сумма.

Запись:

```js
totalExecutionTime += executionTime;
```

эквивалентна:

```js
totalExecutionTime = totalExecutionTime + executionTime;
```

Среднее значение можно получить, разделив накопленную сумму на количество элементов:

```js
const averageTime = totalExecutionTime / testCount;
```

**Важно:** накопитель обычно инициализируется до цикла, изменяется внутри него, а итоговый результат выводится или используется после цикла.

## 9. Типичные ошибки при работе с циклами

### 9.1. Неправильное условие завершения

```js
for (let i = 1; i < 5; i++) {
  console.log(i);
}
```

Такой цикл выведет числа от 1 до 4, а не до 5.

Если нужно включить конечное значение, используй `<=`.

### 9.2. Забытый инкремент

```js
let i = 1;

while (i <= 5) {
  console.log(i);
}
```

Счётчик не изменяется, поэтому цикл становится бесконечным.

### 9.3. Неправильное расположение `break`

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    break;
  }

  console.log(i);
}
```

После достижения значения `3` цикл полностью прекращается.

Код после `break` в этой итерации не выполняется.

### 9.4. Путаница между `break` и `continue`

`break` завершает весь цикл.

`continue` пропускает только текущую итерацию.

Это разные механизмы управления выполнением.

### 9.5. Накопление внутри цикла и вывод результата

Если нужно получить общую сумму, накопитель должен находиться вне цикла, а операция сложения — внутри.

Неправильный подход:

```js
for (let i = 1; i <= 5; i++) {
  let total = 0;
  total += 3;
}
```

На каждой итерации создаётся новая переменная `total`, поэтому накопления не происходит.

Правильный подход:

```js
let total = 0;

for (let i = 1; i <= 5; i++) {
  total += 3;
}
```

## 10. Краткая шпаргалка

| Конструкция | Назначение                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `for`                | Цикл со счётчиком, когда количество повторений известно или удобно задать |
| `while`              | Цикл, выполняющийся, пока условие истинно                                                             |
| `do...while`         | Цикл, который гарантированно выполняется хотя бы один раз                               |
| `break`              | Полностью завершает цикл                                                                                           |
| `continue`           | Пропускает текущую итерацию                                                                                     |
| `i++`                | Увеличивает значение на 1                                                                                           |
| `i--`                | Уменьшает значение на 1                                                                                               |
| `i += value`         | Прибавляет значение к переменной                                                                            |
| `total = 0`          | Типичная инициализация переменной-накопителя                                                    |

## Задание 3. Retry Mechanism

**Файл:** `task3.js`

Исходные данные:

```js
let attempt = 1;
const maxAttempts = 5;
const successfulAttempt = 3;
```

Необходимо реализовать механизм повторного выполнения теста.

Требования:

1. Использовать цикл `while`.
2. На каждой итерации выводить `Attempt N`.
3. Если номер текущей попытки совпадает с `successfulAttempt`:
   - Вывести `Test passed`.
   - Прекратить цикл через `break`.
4. Если все пять попыток завершились без успеха:
   - Вывести `Test failed` после завершения цикла.

Ожидаемый результат с текущими исходными данными:

```text
Attempt 1
Attempt 2
Attempt 3
Test passed
```

Дополнительная проверка: попробуй изменить `successfulAttempt` на `6`. Тогда цикл должен выполнить все пять попыток и вывести `Test failed`.
