# Урок 06. Objects

## Цель урока

Научиться создавать и использовать объекты JavaScript, работать с их свойствами и методами, обращаться к вложенным объектам и проверять содержимое объектов.

Объекты широко используются в AQA: для хранения тестовых данных, конфигураций, параметров запросов и ответов API.

## 1. Что такое объект

**Объект (Object)** — это структура данных, которая хранит набор свойств в формате «ключ — значение» (`key — value`).

В отличие от массива, который предназначен для хранения упорядоченного набора элементов с числовыми индексами, объект позволяет обращаться к данным по именованным ключам.

Пример:

```js
const user = {
  name: "Alex",
  age: 25,
  isActive: true,
};
```

В этом объекте:

- `name`, `age`, `isActive` — ключи (имена свойств).
- `"Alex"`, `25`, `true` — значения свойств.

Объект может содержать значения разных типов, в том числе другие объекты и функции.

### Создание пустого объекта

```js
const testCase = {};
```

Для создания объекта обычно используют фигурные скобки `{}`.

## 2. Чтение свойств объекта

Существует два основных способа получить значение свойства объекта.

### Точечная нотация (Dot Notation)

```js
const testCase = {
  title: "Login test",
  status: "PASSED",
};

console.log(testCase.title);
console.log(testCase.status);
```

Точечная нотация используется, когда имя свойства известно заранее и является допустимым идентификатором JavaScript.

### Квадратная нотация (Bracket Notation)

```js
console.log(testCase["title"]);
console.log(testCase["status"]);
```

Квадратная нотация позволяет обращаться к свойствам по строковому имени.

Она особенно полезна, когда имя свойства хранится в переменной:

```js
const propertyName = "title";

console.log(testCase[propertyName]);
```

В этом случае JavaScript использует значение переменной `propertyName` как имя свойства.

Важно различать:

```js
testCase.propertyName;
testCase[propertyName];
```

Первый вариант обращается к свойству с именем `propertyName`.

Второй вариант обращается к свойству, имя которого содержится в переменной `propertyName`.

## 3. Изменение свойств объекта

Свойства существующего объекта можно изменять.

```js
const testCase = {
  title: "Login test",
  status: "PASSED",
};

testCase.status = "FAILED";

console.log(testCase.status);
```

Результат:

```text
FAILED
```

### Добавление нового свойства

Если указанного свойства ещё нет, присваивание создаёт его:

```js
testCase.browser = "Chrome";
testCase.duration = 1500;
```

Теперь объект содержит новые свойства `browser` и `duration`.

### Удаление свойства

Для удаления свойства используется оператор `delete`:

```js
delete testCase.browser;
```

После выполнения этой операции свойство `browser` будет удалено из объекта.

## 4. `const` и объекты

Объект можно объявить через `const` и при этом изменять его свойства.

```js
const user = {
  name: "Alex",
};

user.name = "John";
user.age = 25;
```

Это допустимо.

Причина заключается в том, что `const` запрещает повторное присваивание переменной, но не запрещает изменение содержимого объекта, на который она ссылается.

Следующий код вызовет ошибку:

```js
const user = {
  name: "Alex",
};

user = {
  name: "John",
};
```

Здесь происходит попытка присвоить переменной `user` совершенно другой объект.

**Запомнить:**

- `const` запрещает переназначение переменной.
- `const` не делает объект неизменяемым.
- Свойства объекта, объявленного через `const`, можно добавлять, изменять и удалять.

## 5. Вложенные объекты (Nested Objects)

Объект может содержать другие объекты в качестве значений своих свойств.

Пример:

```js
const apiResponse = {
  statusCode: 200,
  data: {
    userId: 15,
    name: "Alex",
    isActive: true,
  },
};
```

Здесь `data` — свойство объекта `apiResponse`, значением которого является другой объект.

Для доступа к вложенным свойствам используется последовательное обращение через точечную или квадратную нотацию:

```js
console.log(apiResponse.statusCode);
console.log(apiResponse.data.userId);
console.log(apiResponse.data.name);
console.log(apiResponse.data.isActive);
```

Можно комбинировать оба способа:

```js
console.log(apiResponse["data"].userId);
console.log(apiResponse.data["userId"]);
```

Вложенные объекты часто встречаются в ответах API, конфигурациях и тестовых данных.

## 6. Методы объектов (Object Methods)

**Метод объекта** — это функция, которая является свойством объекта.

Пример:

```js
const user = {
  name: "Alex",

  sayHello: function () {
    console.log("Hello!");
  },
};

user.sayHello();
```

Функцию, объявленную внутри объекта, можно вызвать через точечную нотацию и круглые скобки.

Существует и сокращённый синтаксис объявления методов:

```js
const user = {
  name: "Alex",

  sayHello() {
    console.log("Hello!");
  },
};

user.sayHello();
```

Оба варианта создают метод объекта.

## 7. Проверка наличия свойств

JavaScript предоставляет несколько способов проверить, существует ли определённое свойство объекта.

### Оператор `in`

Оператор `in` проверяет наличие свойства в объекте или в его цепочке прототипов.

```js
const testCase = {
  title: "Login test",
  status: "PASSED",
};

console.log("title" in testCase);
console.log("error" in testCase);
```

Результат:

```text
true
false
```

Оператор возвращает:

- `true`, если свойство найдено.
- `false`, если свойство не найдено.

Важно: `in` проверяет не только собственные свойства объекта, но и унаследованные.

### Метод `Object.hasOwn()`

`Object.hasOwn()` проверяет, является ли свойство собственным свойством объекта.

```js
const testCase = {
  title: "Login test",
  status: "PASSED",
};

console.log(Object.hasOwn(testCase, "title"));
console.log(Object.hasOwn(testCase, "error"));
```

Результат:

```text
true
false
```

В отличие от `in`, этот метод не учитывает свойства, унаследованные через цепочку прототипов.

### Разница между `in` и `Object.hasOwn()`

| Оператор / метод  | Что проверяет                         |
| ----------------- | ------------------------------------- |
| `in`              | Собственные и унаследованные свойства |
| `Object.hasOwn()` | Только собственные свойства           |

Для проверки наличия конкретного свойства непосредственно в объекте обычно используют `Object.hasOwn()`.

## 8. Получение информации о свойствах объекта

JavaScript предоставляет встроенные методы для получения ключей, значений и пар ключ-значение объекта.

### `Object.keys()`

Возвращает массив собственных перечисляемых строковых ключей объекта.

```js
const testResult = {
  title: "Payment test",
  status: "PASSED",
  duration: 2300,
};

console.log(Object.keys(testResult));
```

Результат:

```js
["title", "status", "duration"];
```

### `Object.values()`

Возвращает массив значений собственных перечисляемых строковых свойств объекта.

```js
console.log(Object.values(testResult));
```

Результат:

```js
["Payment test", "PASSED", 2300];
```

### `Object.entries()`

Возвращает массив пар вида `[ключ, значение]` для собственных перечисляемых строковых свойств объекта.

```js
console.log(Object.entries(testResult));
```

Результат:

```js
[
  ["title", "Payment test"],
  ["status", "PASSED"],
  ["duration", 2300],
];
```

### Сравнение методов

| Метод              | Что возвращает               |
| ------------------ | ---------------------------- |
| `Object.keys()`    | Массив ключей                |
| `Object.values()`  | Массив значений              |
| `Object.entries()` | Массив пар «ключ — значение» |

Все три метода возвращают массивы и не изменяют исходный объект.

## 9. Объекты в AQA

Объекты особенно важны в автоматизированном тестировании, поскольку позволяют удобно хранить связанные данные.

### Хранение тестовых данных

```js
const testCase = {
  title: "Login test",
  status: "PASSED",
  priority: "High",
};
```

### Хранение конфигурации

```js
const config = {
  baseUrl: "https://example.com",
  timeout: 5000,
  browser: "Chrome",
};
```

### Работа с ответами API

```js
const response = {
  statusCode: 200,
  data: {
    id: 15,
    name: "Alex",
  },
};
```

Такие структуры позволяют обращаться к конкретным значениям и использовать их в проверках.

## 10. Частые ошибки

1. **Путаница между точечной и квадратной нотацией**

   `object.property` обращается к свойству с именем `property`, а `object[property]` использует значение переменной `property`.

2. **Ожидание, что `const` запрещает изменение объекта**

   `const` запрещает переназначение переменной, но не изменение свойств объекта.

3. **Неправильное обращение к вложенным свойствам**

   Для доступа к `userId` внутри `data` необходимо использовать `apiResponse.data.userId`.

4. **Путаница между `in` и `Object.hasOwn()`**

   `in` учитывает цепочку прототипов, а `Object.hasOwn()` проверяет только собственные свойства.

5. **Ожидание, что `Object.keys()` и `Object.values()` вернут объект**

   Эти методы возвращают массивы, а не новый объект.

## 11. Краткая шпаргалка

| Операция                       | Синтаксис                    |
| ------------------------------ | ---------------------------- |
| Создание объекта               | `const obj = {}`             |
| Чтение свойства                | `obj.name`                   |
| Чтение через квадратные скобки | `obj["name"]`                |
| Чтение по динамическому ключу  | `obj[key]`                   |
| Изменение свойства             | `obj.name = "Alex"`          |
| Добавление свойства            | `obj.age = 25`               |
| Удаление свойства              | `delete obj.age`             |
| Вызов метода                   | `obj.method()`               |
| Проверка наличия свойства      | `"name" in obj`              |
| Проверка собственного свойства | `Object.hasOwn(obj, "name")` |
| Получение ключей               | `Object.keys(obj)`           |
| Получение значений             | `Object.values(obj)`         |
| Получение пар ключ-значение    | `Object.entries(obj)`        |

# Границы урока

В этом уроке рассматриваются базовые операции с объектами JavaScript.

Следующие темы пока не входят в программу урока:

- Деструктуризация объектов.
- Spread и Rest.
- Продвинутые методы работы с объектами.

Эти темы будут рассмотрены отдельно, если они понадобятся в дальнейшем обучении.

**Результат урока:** умение создавать объекты, читать и изменять их свойства, работать с вложенными структурами и проверять содержимое объектов — базовый фундамент для дальнейшей работы с API, тестовыми данными и автоматизированными тестами.
