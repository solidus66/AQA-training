# 01. Основы JavaScript

## 1. Переменные

В JavaScript есть два основных способа объявления переменных: `const` и `let`.

### const

Используется для переменных, которые не будут переназначаться.

```js
const browser = "Chrome";
const statusCode = 200;
```

Попытка переназначить значение приведёт к ошибке:

```js
const appName = "CalcBite";
appName = "TestApp"; // Ошибка
```

### let

Используется, когда значение переменной может изменяться.

```js
let retryCount = 3;
retryCount = 5; // Работает
```

**Правило:** используй `const` по умолчанию. Если значение должно изменяться — `let`.

`var` — устаревший способ объявления переменных. В современном JavaScript без необходимости его использовать не стоит.

## 2. Типы данных

JavaScript использует несколько основных типов данных.

| Тип         | Пример          | Назначение                     |
| ----------- | --------------- | ------------------------------ |
| `string`    | `"Chrome"`      | Строка                         |
| `number`    | `200`, `3.14`   | Число                          |
| `boolean`   | `true`, `false` | Логическое значение            |
| `undefined` | `undefined`     | Значение не задано             |
| `null`      | `null`          | Намеренное отсутствие значения |

Пример:

```js
const browser = "Firefox";
const responseCode = 200;
const isAuthorized = true;

let errorMessage;
const testData = null;
```

### Оператор typeof

Оператор `typeof` позволяет определить тип значения.

```js
console.log(typeof browser); // "string"
console.log(typeof responseCode); // "number"
console.log(typeof isAuthorized); // "boolean"
console.log(typeof errorMessage); // "undefined"
```

**Особенность JavaScript:**

```js
console.log(typeof null); // "object"
```

Это историческая особенность языка. `null` не является объектом, несмотря на результат `typeof`.

## 3. Арифметические операторы

Основные арифметические операторы:

| Оператор | Назначение         | Пример   | Результат |
| -------- | ------------------ | -------- | --------- |
| `+`      | Сложение           | `10 + 5` | `15`      |
| `-`      | Вычитание          | `10 - 5` | `5`       |
| `*`      | Умножение          | `10 * 5` | `50`      |
| `/`      | Деление            | `10 / 5` | `2`       |
| `%`      | Остаток от деления | `10 % 3` | `1`       |

Пример:

```js
const total = 100 + 50;
const difference = 100 - 50;
const product = 10 * 5;
const division = 100 / 4;
const remainder = 10 % 3;

console.log(total);
console.log(difference);
console.log(product);
console.log(division);
console.log(remainder);
```

## 4. Операторы сравнения

Операторы сравнения позволяют проверять отношения между значениями.

Результатом сравнения всегда будет `boolean`: `true` или `false`.

| Оператор | Назначение          |
| -------- | ------------------- |
| `===`    | Строгое равенство   |
| `!==`    | Строгое неравенство |
| `>`      | Больше              |
| `<`      | Меньше              |
| `>=`     | Больше или равно    |
| `<=`     | Меньше или равно    |

Примеры:

```js
console.log(200 === 200); // true
console.log(200 !== 500); // true
console.log(200 > 100); // true
console.log(200 < 100); // false
```

### Разница между == и ===

В JavaScript есть два оператора равенства:

- `==` — сравнивает значения с автоматическим приведением типов.
- `===` — сравнивает значения без автоматического приведения типов.

Пример:

```js
console.log(200 == "200"); // true
console.log(200 === "200"); // false
```

В первом случае JavaScript приводит строку к числу перед сравнением.

Во втором случае сравниваются и значение, и тип данных.

**Для проверок в автотестах предпочтительно использовать `===` и `!==`.** Это позволяет избежать неожиданных результатов из-за автоматического приведения типов.

## 5. Логические операторы

Логические операторы позволяют объединять несколько условий.

| Оператор | Название | Назначение                          |
| -------- | -------- | ----------------------------------- |
| `&&`     | AND (И)  | Все условия должны быть истинными   |
| `\|\|`   | OR (ИЛИ) | Достаточно одного истинного условия |
| `!`      | NOT (НЕ) | Инвертирует логическое значение     |

Пример использования `&&`:

```js
const actualStatus = 200;

console.log(actualStatus >= 200 && actualStatus <= 299);
// true
```

Оба условия должны выполняться одновременно.

Пример использования `||`:

```js
const browser = "Chrome";

console.log(browser === "Chrome" || browser === "Firefox");
// true
```

Достаточно, чтобы хотя бы одно условие было истинным.

Пример использования `!`:

```js
const isAuthorized = false;

console.log(!isAuthorized); // true
```

## 6. Шаблонные строки (Template literals)

Шаблонные строки позволяют вставлять значения переменных непосредственно в текст.

Для этого используются обратные кавычки `` ` `` и конструкция `${...}`.

Пример:

```js
const browser = "Chrome";
const version = 157;

const message = `Browser: ${browser}, version: ${version}`;

console.log(message);
```

Результат:

```text
Browser: Chrome, version: 157
```

В отличие от обычных строк, шаблонные строки позволяют удобно объединять текст и значения переменных без использования оператора `+`.
